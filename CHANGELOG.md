# Changelog

Changes to Context's MCP servers and to this repository, newest first. Dates are UTC. The format is loosely
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

[TOOLS.md](TOOLS.md) is regenerated from the servers' own `tools/list` answers whenever their tools change.

## 2026-10-29
