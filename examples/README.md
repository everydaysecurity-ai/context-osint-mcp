# Worked examples

One example per indicator type. Each shows a prompt you might give your assistant, the tool calls it
typically makes, and the shape of the evidence that comes back.

> **All outputs here are illustrative.** Tool names, arguments and top-level result fields match the real
> servers (see [TOOLS.md](../TOOLS.md)). Nested values are made up to show the shape of an answer. That includes
> attribute keys, source names, relationship labels, statuses, and crawler analysis fields. Every indicator and value is synthetic: reserved example domains (`example.com`,
> `example.net`, `example.org`), documentation IP ranges (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`),
> documentation ASNs (`AS64496` to `AS64511`), fictional `555-01xx` phone numbers, and made-up names. None of it
> describes a real person, company or site. Attribute keys and timeline wording are abbreviated, and real
> responses carry more fields.

Your assistant chooses its own calls, so the sequence you see may differ.
